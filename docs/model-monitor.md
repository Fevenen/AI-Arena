# 模型监控与独立推理配置

在侧栏打开「模型监控」，在当前页面切换。活动请求、逐次记录、耗时趋势与按条件统计会自动更新。从棋局切到监控会保留棋局连接；关闭页面或离开棋局与监控页后，沿用原有的会话释放与暂停机制。固定局面测速可在页面取消，服务退出时会取消其请求。

## 按对局查看双方耗时

顶部并列「全部对局／某一对局」「全部模型」「全部桌游」三个筛选，条件取交集，滚动时保持可见。默认全部对局显示简要总览；选择一盘棋后，显示该局各方平均耗时和逐步柱状图。累计、最慢、推理设置等收在「更多统计」，逐步表格默认收起。对局与回放页的「本局耗时」会直接选中该局；查看监控期间原棋局连接继续保留。

棋盘下方直接提供平均与最近一步耗时，逐步图表和表格按需展开，随落子更新。表格可滚动查看所有步骤，查看旧步骤时新落子不会强制拉回底部。推理、任务、模式和规则辅助位于「更多筛选」；「分组统计」表示把相同模型、推理设置和游戏的请求汇总，默认收起。请求明细和固定局面测速也默认收起，测速只在实际运行时提示「正在测速」。

图表纵轴标注秒和刻度。按各方第几次行动分组绘制不同颜色的柱状图；四人桌游同样支持。表格同时保留棋谱全局步数，可直接跳到该步回放。选定对局后保持该选择，不自动跳到其他对局；导出与当前筛选范围一致。

“整步耗时”采用棋谱记录的完成时间，包含该次落子的等待与重试。“思考输出阶段”只在首输出、正文开始两个时间点均存在时计算差值，不代表完整模型内部思考时间。末次首输出采用最后一次请求的时间点；缺失数据不推算。真人行动与系统自动处理不伪造为零秒思考。失败、取消的请求单独保留，不混入已落子耗时平均值。

## 分别设置棋手和聊天

- 「模型管理 → 编辑」中分别设置推理协议、思考开关、该协议支持的原生强度及总输出上限。多个配置可以复用同一个服务和 Model ID。
- DeepSeek 原生强度为 `low / high / max`，关闭思考使用供应商开关。
- Qwen 模式只发送 `chat_template_kwargs.enable_thinking`。KVMem 的 `low / medium / high` 单独标注为引擎扩展，不代表模型官方训练档位。
- 未确认能力的接口默认不发送推理覆盖字段。用户可为兼容服务明确选择协议；上游仍可能拒绝或忽略不支持的参数。
- 大肥鱼连接设置中有独立的棋手思考配置和输出预算。日常聊天、意图判断、自动点评和酒馆陪玩默认显式关闭思考。Arena 提问勾选「深入分析」时仅该次问题开启思考。
- 以上配置不写入 KVMem 的共享设置；跟随服务时会尽可能记录本地 `/props` 的默认值快照，不能将这个快照当作上游对某次请求的执行证明。
- 限时模式保留所选推理设置和输出预算。时间到仍可能没有合法动作，不能保证任意模型在时限内生成其最佳着法。

## 读懂指标

每次模型尝试单独记录，失败、超时、取消、截断也进入统计。首输出包含思考输出；答案开始表示首个正文输出，合法落子还需要通过游戏校验。排队与流式时间点均以进入该次请求为起点；接口未提供的用量与阶段显示未知。旧棋谱只提供已成功落子的耗时，其档位未验证，不能代表完整成功率。

统计按模型、协议与推理设置、任务、游戏、规则辅助、正常／限时及测速类型区分。原生同名档位也不意味着跨模型相等的计算量。输出用量通常包含思考，不能把思考 tokens 再累加一次。

本地模型通过跨进程队列共享同一服务：限时落子、主动聊天、普通落子、测速／自动点评按优先级等待；已经在执行的请求不被强行抢占。后台点评繁忙时跳过，不积压旧点评。点击「暂停对局后聊天」会保留当前步，完成后暂停。

取消会关闭客户端连接并释放排队资源；具体上游何时停止 GPU 计算由推理引擎决定。外部程序如果绕过本项目直接访问同一个模型，不受此队列控制。

## 固定局面测速

选一个已保存对局及步数，选择模型、原生推理设置、纯模型或规则辅助，以及每组 1–5 次重复。后台从原始种子和已执行动作重建相同局面，并复用落子提示词生成逻辑；不更改原对局。各组共用相同提示词、温度、输出预算与超时，并轮换执行顺序，记录提示词哈希。

测速会实际请求模型并产生用量；可取消。显示耗时、用量和合法率，合法率不等于棋力评分。模型服务未锁定版本、缓存、网络和机器负载仍会影响结果。

## 数据与发布

Arena 指标保存在配置文件旁的 `model-monitor/requests.jsonl`，桌宠指标在其私有数据目录的 `model-monitor/`。默认不记录提示词、回答、图片、API Key 或完整思考文本。可按筛选导出指标。运行数据遵循项目忽略规则，不进入 GitHub 源码。

桌宠不在线时 Arena 仍独立运行，只暂时无法读取桌宠指标。升级桌宠桥接补丁时同时复制 `bridge/inference.py` 与相应调用模块。
