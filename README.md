# AI Arena · 本机 AI 桌游竞技场

一个在 Windows 本机运行、可独立发布的 AI 桌游竞技场。浏览器选择桌游、安排座位、开始对局或查看记录；模型、内置机器人、真人和大肥鱼可以在同一桌混坐。

当前正式游戏有**自由五子棋**、**角斗士棋：双人对决（Blokus Duo）**和**璀璨宝石（2–4 席）**；一个仅供开发/测试的三座位插件用来验证平台接口、私有信息、结算和回放。项目零运行时 npm 依赖，默认只监听 `127.0.0.1`。

## 这一版包含

- **游戏库**：从注册表自动生成游戏卡片和座位配置；正式展示五子棋、角斗士棋和璀璨宝石，测试环境可注入三座位插件。
- **通用座位与回合**：座位 ID、显示名、顺序、人数和行动者由游戏插件声明，不再写死 `black`/`white`。
- **模型落子两种模式**：纯模型（只给规则和局面）与规则辅助（合法候选、立即成五、必堵点、双威胁）。按座位选择并写入对局/历史。
- **推理强度与输出预算**：模型管理可选择推理协议、思考开关、该协议支持的原生强度与输出上限。可分别配置普通模型和大肥鱼棋手。见[模型监控与推理设置](docs/model-monitor.md)。
- **严格结构化落子**：只接受单个完整 JSON；自由文本、含糊、多动作、截断、非法动作拒绝并有限重试。失败不会替换成机器人。
- **大肥鱼观战/棋手**：同一角色，按身份从双方视角或自己的座位说话；自动点评、手动问答、语音开关彼此独立。
- **落子优先的锁调度**：桥内落子优先于自动点评，低优先级点评可被跳过/丢弃；Arena 在轮到棋手时也不启动点评。
- **完整响应超时**：普通模型客户端和桌宠客户端都在正文读取完成后才撤掉计时器；响应头先到、正文卡住也会超时/取消。
- **会话生命周期**：结束、换局、离开、断开、重连会释放/取代桌宠会话；自然终局保留必要终局发言后释放，避免撞 8 个会话上限。
- **权威回放快照**：每步保存公开视图和座位视图；旧棋谱可继续播放，规则版本变化后仍读取快照。公开 API/SSE/导出不返回原始私有状态。
- **逐手指标**：耗时、尝试次数、失败类型、最终动作、finish reason 与 token usage（含 reasoning 计数）；不保存模型内部推理正文或 Key。
- **新大厅与对局 UI**：深色界面、游戏库、动态座位、桌面优先、状态区、聊天标签；SSE 只更新局部，保留输入焦点、光标、IME 组词、滚动和棋盘焦点。
- **可移植**：不依赖固定盘符、用户名、启动工作目录或本站路径；配置相对路径从配置文件目录解析。

## 环境

必需：

- Windows 10/11。
- Node.js 20 或更新（本项目在 Node.js 24 上实测）。
- 现代浏览器（Edge / Chrome / Firefox）。

可选：

- OpenAI 兼容的云端或本机模型。
- 大肥鱼 v0.3.1 + Arena 桥补丁（见 [大肥鱼接入](docs/dafeiyu.md)）。
- 仅运行浏览器冒烟测试时需要 Edge 或 Chrome。

无需 `npm install`。

## 启动

在 PowerShell 中：

```powershell
cd "<你的目录>\AI-Arena"
node apps\server\index.mjs
```

或双击项目根目录的：

```text
start.cmd
```

`start.cmd` 会打开控制台、启动服务并自动打开默认浏览器。切到模型监控时，当前对局继续运行。关闭最后一个对局页面，或离开对局与监控页后，服务会等待短暂的重连宽限期，再暂停该局并释放模型请求和大肥鱼会话。刷新后及时重连会保留对局。Node 服务仍可接受重新打开的网页；要停止服务并释放端口，在启动控制台按 `Ctrl+C`。终端会打印：

```text
本机网页：http://127.0.0.1:8787
```

首次启动自动创建：

```text
data\arena.json          本机配置（从 config/arena.example.json 生成）
data\matches\            对局记录，一局一个 JSON 文件
```

`data\` 被 Git 忽略。修改端口后重启；端口在 `data\arena.json` 的 `server.port`。

## 第一次开一局

1. 打开 `http://127.0.0.1:8787`。
2. 在 **桌游库** 选择「自由五子棋」「角斗士棋：双人对决」或「璀璨宝石」。
3. 可以先用「快速试玩」与内置机器人对局，也可以手动安排各座位。
4. 按当前桌游的界面提示行动，机器人会自动接手自己的回合。
5. 右侧或顶部可暂停、继续、单步、结束。全 AI 对局同样可暂停后单步推进。
6. 结束后进入 **对局记录 → 回放**，用上一手/下一手、时间轴、跳转复盘。

角斗士棋的真人操作是：从托盘选一块棋子 → 可旋转/翻面 → 点棋盘上的左上角锚点，查看绿色合法或红色非法预览 → 点“确认摆放”。只选棋子、旋转、取消或查看非法预览都不会提交动作。

只有大肥鱼会在对局聊天里发 AI 点评或棋手发言。普通云端和本地模型座位只提交游戏动作。

### 安排座位

每个座位可选择：

- **真人**：在本机桌面点击/提交动作（当前版本一局最多一位真人）；
- **内置机器人**：无 Key 的规则启发式对手；
- **普通模型**：竞技场直连的 OpenAI 兼容模型；
- **大肥鱼**：通过本机桌宠桥观战或入座（一局最多一位大肥鱼棋手）。

全 AI 对局可用于观战；测试环境的三座位插件会按插件声明生成三个座位。

## 模型

首次启动自带一个可编辑示例，但**不会自动被座位使用**：

```json
{
  "name": "本地 KVMem（示例）",
  "baseUrl": "http://127.0.0.1:18200/v1",
  "modelId": "kvmem-polystrata-qwen35",
  "apiKey": "local"
}
```

- API Key 可空；非空时发送 `Authorization: Bearer <Key>`。
- Key 只保存在后端 `data\arena.json`；网页只显示是否已设置，对局/日志/回放/导出不包含 Key。
- 支持 Base URL 带 `/v1`、无路径、末尾斜杠或完整 `/chat/completions`。
- 超时和取消覆盖完整响应体，不只是响应头。
- 每个 AI 座位可选 **纯模型** 或 **规则辅助**。

详细步骤和适配器开发见 [添加模型](docs/add-model.md)。

## 大肥鱼

大肥鱼是同一角色，但身份分开：

- **观战**：`role=observer`，看公开局面，从双方视角点评；
- **棋手**：`role=player`，看自己的座位视图，从自己的颜色/处境说话和落子。

安全/生命周期：

- 落子优先于自动点评；棋手正在落子时手动提问会明确提示稍后再问。
- 自动点评失败不会被当作棋手掉线。
- 离开页面/换局会释放会话；有棋手座的棋局暂停，返回后需重连再继续。
- 终局后保留短时间终局发言/语音，再释放会话。
- 关闭语音会取消该会话仍在等待的播报；不影响正常聊天/提醒语音。

公开 Dafeiyu **v0.3.1 不含 Arena 桥**。本仓库提供可直接应用的补丁：

```text
integrations/dafeiyu-v0.3.1-arena-bridge/
```

步骤见 [大肥鱼接入](docs/dafeiyu.md) 和补丁目录 README。没有桌宠时，内置机器人/普通模型仍能完成开局与回放。

## 界面

- 导航：**桌游库 / 对局记录 / 模型管理**。
- 大厅先展示可玩的游戏，再展示选中桌游的座位和规则；五子棋、角斗士棋的棋盘和规则放在选中后的设置/对局页。
- 对局页桌面优先，状态区突出轮到谁、谁在行动、点评状态和暂停原因；暂停/继续/单步只保留一组入口。
- 聊天区区分「观战点评/观战回答」与「<座位> · 大肥鱼」「棋手点评/棋手回答」。
- 实时 SSE 只更新状态、座位、桌面、聊天和控件；输入框节点不被替换，中文输入法组词期间延后更新。
- 逐手指标、规则版本、对局编号、本机地址在详情中。

## 历史、回放与可见性

对局记录支持按玩家/模型、桌游、结果（有胜负/和棋/已中止）、状态和关键词筛选。

- 回放读取本地权威快照，不调用模型、不请求桌宠、不播放语音。
- 旧棋谱在规则版本一致时自动补建快照；有快照后规则版本变化仍可播放；无快照且版本不匹配会明确提示。
- `randomEvents`/`seed` 已为未来发牌、掷骰等随机事件预留。
- 公开 API、SSE、导出只使用 `getPublicState` 和公开聊天/事件；测试插件验证了私有目标不会泄露。
- 导出不包含 Key；`data/` 不会进 Git。

## 可移植与发布

- 代码/默认配置/启动脚本不依赖盘符、用户名或启动目录。
- 配置文件的相对 `storage.matchDir` 按配置文件所在目录解析。
- 公开文件检查：

```powershell
node scripts\check-public.mjs
```

- 发布前从全新目录（可含中文和空格）按本文启动，至少用内置机器人完成开局、终局、重启回放；再运行公开文件检查。
- 不提交 `data/`、`logs/`、`test-results/`、模型权重、缓存或真实 Key。
- 大肥鱼是独立项目；竞技场不复制其角色卡、模型权重或用户配置。桥补丁的许可说明见补丁目录。

## 已知限制

- 正式桌游为自由五子棋、角斗士棋：双人对决和璀璨宝石；三座位插件只用于开发和测试，默认不注册。
- 一局最多一位真人、一位大肥鱼棋手。
- 模型可能给出合法但很差的动作；规则辅助只是提示，不是多步搜索。
- Dafeiyu 游戏模型使用桥的 `kvmem_*` 配置，和桌宠主聊天模型可以不同。
- 桌面端真实 TTS 未进行人工听音验收；日志/队列已验证。
- 未模拟长时间断网或公网部署；默认单机、本机监听。
- 本机配置文件里的 Key 是明文，适合单人本机，不适合共享机器。

## 璀璨宝石与桌宠同步

在大厅选择璀璨宝石、2–4 席，以及「正常模式」或「限时模式」。正常模式沿用模型配置的超时，限时模式每手与重试共用 25 秒预算。观战或大肥鱼入座时，打开的对局会同步到桌宠的「竞技场」控件。桌宠启动环境可用 DAFEIYU_ARENA_URL 设置其他本机地址。

## 模型监控与原生推理设置

侧栏「模型监控」支持按对局、模型、桌游筛选，可查看各座位步耗时、请求明细和固定局面测速。棋手可开启思考，同时保持桌宠聊天与点评关闭思考；限时模式保留所选推理参数。参见 [使用与指标说明](docs/model-monitor.md)。
