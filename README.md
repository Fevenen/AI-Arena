# 鲸局 · AI 桌游竞技场

一个在 Windows 本机运行的 AI 桌游竞技场。第一版提供：

- **自由五子棋**：15×15、黑先、无禁手、五连及以上获胜、满盘和棋；终局标出胜利连线。
- **两个独立座位**：各自选择真人、内置机器人、普通模型或大肥鱼。
- **模型管理**：新增、编辑、删除、测试连接；支持 OpenAI 兼容的云端和本地服务、空 Key、自定义 Bearer Key。
- **对局控制**：落子、暂停、继续、单步推进、重试、结束；全 AI 对局可观战。
- **持久化与回放**：历史筛选、逐手复盘、跳转、当时公开发言同步显示；重启后仍可打开。
- **大肥鱼桌宠接入**：观战者、棋手、手动问答、关键事件自动点评、文字/语音独立开关、掉线暂停与重连。
- **可移植发布**：零运行时 npm 依赖；源码和配置不依赖固定盘符、用户名或工作目录。

> 这是单人本机应用。默认只监听 `127.0.0.1`，不要直接暴露到公网。

---

## 1. 环境要求

必需：

- Windows 10/11。
- **Node.js 20 或更新版本**（本项目在 Node.js 24 上实测）。
- 一个现代浏览器（Edge、Chrome、Firefox 均可）。浏览器访问本机网页。

不需要：

- 不需要 `npm install`。项目没有第三方运行时依赖。
- 不需要 API Key 也能完整试玩：使用内置机器人。
- 不需要大肥鱼或 KVMem 也能使用模型管理、五子棋、历史与回放。

可选：

- 一个 OpenAI 兼容模型服务（云端供应商或本机服务）。
- 大肥鱼桌宠（需要带竞技场桥的版本，见 [大肥鱼接入](docs/dafeiyu.md)）。
- 仅运行浏览器冒烟测试时需要 Edge 或 Chrome。

检查 Node 是否可用：

```powershell
node --version
```

## 2. 安装与启动

在 PowerShell 中：

```powershell
cd "<你的目录>\AI-Arena"
node apps\server\index.mjs
```

或直接双击项目根目录的：

```text
start.cmd
```

启动后终端会打印：

```text
本机网页：http://127.0.0.1:8787
```

在浏览器打开这个地址即可。

第一次启动会自动创建：

```text
data\arena.json          本机配置（首次启动从 config/arena.example.json 生成）
data\matches\            对局记录，一局一个 JSON 文件
```

`data\` 已排除在 Git 之外。项目不依赖启动时所在目录：即使在另一个工作目录用绝对路径启动，资源仍从项目根目录和配置文件位置解析。

### 修改端口

先启动一次生成 `data\arena.json`，关闭服务，然后修改：

```json
"server": { "host": "127.0.0.1", "port": 8787 }
```

重新启动。若只临时改端口，也可以：

```powershell
$env:ARENA_PORT = 8899
node apps\server\index.mjs
```

`ARENA_PORT` 是高级/测试便利项，不会写入配置文件。

## 3. 第一次开一局

### 最快：和内置机器人下

1. 打开 `http://127.0.0.1:8787`。
2. 点击「快速试玩：我执黑 vs 内置机器人」。
3. 在棋盘空点上点击落子，例如中央 `H8`。
4. 机器人自动回手。右侧可暂停、结束对局。
5. 结束后进入「历史记录」→「回放」，用「上一手 / 下一手 / 时间轴 / 跳转」复盘。

### 用模型

1. 打开「模型管理」。
2. 首次启动自带一个可编辑的「本地 KVMem（示例）」配置：
   - Base URL：`http://127.0.0.1:18200/v1`
   - Model ID：`kvmem-polystrata-qwen35`
   - API Key：`local`
   这只是示例，**不会自动被任何座位使用**。你可以直接编辑、测试，或删除后新增自己的配置。
3. 点击「测试连接」。界面会分别说明配置、地址、认证与模型哪一项失败。
4. 保存后回到「开桌」，把黑方/白方任一席改为「普通模型」，选择刚保存的配置，开始对局。
5. 两个座位可以指向两个不同的供应商或本机服务。Key 只在后端使用，网页只显示「已设置」。

没有 Key 的本地服务：API Key 留空即可，服务不会发送 `Authorization` 头。

### 和大肥鱼下或看她观战

1. 按 [大肥鱼接入](docs/dafeiyu.md) 启动带 Arena 桥的桌宠后端。
2. 回到开桌页，点击大肥鱼面板里的「检测」；显示「桌宠在线」后再开始。
3. **观战**：勾选「邀请她观战」，开始对局。右侧会出现大肥鱼聊天区。
4. **棋手**：把黑方或白方身份改为「大肥鱼 · 桌宠棋手」。她轮到时会通过桌宠落子，落点仍由竞技场后端校验。
5. 自动点评、语音播报可以分别开关；手动提问始终可用（连接正常时）。
6. 棋手掉线时对局自动暂停，点击「重新连接」后再按「继续 / 重试本手」。

### 全 AI 观战

两个座位都选择模型、机器人或大肥鱼后开始。右侧顶部可暂停；暂停后可「继续」或「单步」推进。AI 与 AI 的棋局仍会持久记录。

## 4. 模型配置说明

字段：

| 字段 | 说明 |
| --- | --- |
| 显示名称 | 网页和座位里显示的名称 |
| 接口类型 | 第一版为 OpenAI 兼容 Chat Completions |
| Base URL | 例如 `http://127.0.0.1:18200` 或 `.../v1`，末尾斜杠会被处理 |
| Model ID | 供应商或本地服务的模型名 |
| API Key | 可空；有值时后端发送 `Authorization: Bearer <Key>` |
| 超时 | 毫秒；连接测试和对局请求都使用 |
| 重试次数 | 非法落子/可重试错误的额外尝试次数 |

请求端点规则：

- `http://host:18200` → `http://host:18200/v1/chat/completions`
- `http://host:18200/v1` → `http://host:18200/v1/chat/completions`
- 完整 `/chat/completions` 地址保持不变。

更多说明、错误排查和供应商适配器开发方法见 [添加模型](docs/add-model.md)。

安全边界：

- Key 只写入后端 `data\arena.json`。
- 模型列表/详情接口不返回 Key。
- 对局记录、日志、回放导出不写入 Key。
- 网页的 CSP、同源检查和仅本机监听降低外部页面误操作风险。

## 5. 对局规则与操作

- 列 A-O 从左到右，行 15-1 从上到下；**H8 是中央天元**。
- 界面、模型提示、动作记录、事件和回放统一使用该坐标。
- 所有落子（真人、普通模型、大肥鱼、机器人）都经后端统一校验：
  - 是否该座位行动、是否轮到它、坐标是否在棋盘内、是否空点、是否终局。
  - 非法动作不改变棋盘。模型动作有限重试；超时或重试耗尽后暂停，并显示原因。
- 重复点击/重复请求使用提交标识去重；暂停或结束后迟到的 AI 回复会被丢弃。
- 暂停、继续、单步和结束不会丢失已接受的动作与公开发言。
- 每个持久化快照带有递增 `revision`，网页拒绝旧响应覆盖新 SSE 局面。

## 6. 历史、回放与数据

「历史记录」支持按玩家/模型、结果、状态和关键词筛选。

回放提供：

- 上一手、下一手；
- 可拖动时间轴；
- 跳到指定手数；
- 棋盘、最后一手、公开发言和结果同步；
- 终局胜利连线。

回放只读取本地记录，不调用模型、不请求大肥鱼、不播放语音。

本机记录包含：

- 游戏及规则版本、随机种子；
- 开局座位、模型名称与不敏感连接快照；
- 已接受动作及来源；
- 公开发言与关键错误；
- 结果、暂停/恢复事件；
- 未来游戏可用的 `randomEvents`、`privateBySeat` 结构占位。

数据目录是 `data\`。备份时复制整个 `data\` 即可。配置里的 API Key 是明文本机文件，请勿提交 Git 或分享。

## 7. 测试

运行全部自动测试：

```powershell
node --test --test-concurrency=1
```

或：

```powershell
node scripts\verify.mjs
```

浏览器冒烟测试（需要 Edge/Chrome；会使用临时配置和临时端口，不会改动 `data\arena.json`；截图写入 `data\ui-check\`）：

```powershell
node scripts\ui-smoke.mjs
```

模拟一个 OpenAI 兼容模型服务（用于无真实 Key 的联调）：

```powershell
node tools\mock-openai.mjs
```

然后新增模型：

- Base URL：`http://127.0.0.1:18999/v1`
- Model ID：`mock-gomoku`
- API Key：`local`

公开文件检查（发布前）：

```powershell
node scripts\check-public.mjs
```

测试覆盖范围见 [验证记录](docs/verification.md)。

## 8. 目录结构

```text
AI-Arena/
  apps/
    web/                原生 HTML/CSS/JS 网页（无需构建）
    server/             本机 HTTP API、SSE、调度、持久化、桌宠客户端
  packages/
    core/               游戏接口、规则错误、可见性、回放构建
    games/              五子棋实现与游戏注册
    models/             模型适配器 registry、OpenAI 兼容协议、内置机器人
  config/
    arena.example.json  可复制的本机配置示例
  data/                 本机配置与对局数据（Git 忽略，仅保留 .gitkeep）
  docs/                 模型、桌游、大肥鱼接入与验证文档
  scripts/              验证、公开文件检查、浏览器冒烟测试
  tests/                规则、模型、调度、API 与桌面桥接模拟测试
  tools/                零依赖模拟模型服务
  start.cmd
  package.json
  package-lock.json
  README.md
```

## 10. GitHub 发布清单

- 不提交 `data/`、`logs/`、`test-results/`、模型权重、构建缓存或任何真实 Key。
- 运行 `node scripts/check-public.mjs`。
- `package.json` 与 `package-lock.json` 在仓库根目录。
- 配置模板使用占位值或明确标注的本地示例。
- 发布后从全新目录按本 README 启动，并至少用内置机器人完成开桌、终局、回放。
- 大肥鱼是独立项目；竞技场不复制其角色卡、模型权重或个人配置。
